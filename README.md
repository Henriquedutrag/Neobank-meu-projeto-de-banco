## 🌟 Visão Geral

O **NeoBot Bank** nasceu como um projeto acadêmico focado em criar uma experiência de usuário (UX) fluida, moderna e segura para serviços financeiros digitais. Além do gerenciamento básico de conta e movimentações fictícias, o sistema conta com o **NeoBot**, um assistente virtual programado para tirar dúvidas frequentes e auxiliar no uso da plataforma.

---

## 🚀 Funcionalidades

- **Dashboard Financeiro:** Visualização clara do saldo disponível, extrato e histórico de transações.
- **Simulação de Transferências:** Envio de valores fictícios entre contas em tempo real com validação de saldo.
- **Assistente Virtual (NeoBot):** Chatbot interativo pronto para auxiliar no atendimento ao usuário.
- **Interface Dark Mode:** Design minimalista focado na usabilidade, inspirado no ecossistema de fintechs atuais.
- **Responsividade Total:** Layout adaptado para uso em desktops, tablets e smartphones.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido com as seguintes tecnologias:

- **HTML5:** Estruturação semântica das páginas.
- **CSS3:** Estilização moderna, variáveis CSS, layout com Flexbox/Grid e efeitos visuais *Dark Mode*.
- **JavaScript (ES6+):** Manipulação de DOM, regras de negócio bancárias e lógica do chatbot.

## ⚙️ Como Executar o Projeto

### Pré-requisitos
Para rodar este projeto localmente, você só precisa de um navegador web atualizado (Google Chrome, Firefox, Edge, Safari, etc.).

### Passo a Passo

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/neobot-bank.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd neobot-bank
   ```

3. **Abra o arquivo principal:**
   - Basta dar um duplo clique no arquivo `index.html` ou abri-lo diretamente no seu navegador de preferência.
   - *(Opcional)* Se utilizar o VS Code, execute com a extensão **Live Server**.
